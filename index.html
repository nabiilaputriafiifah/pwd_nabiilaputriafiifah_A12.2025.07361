System Analysis & Design

Information System Design - Pita Emas Wedding Decoration

A mid-term system analysis project designing a complete information system for a wedding decoration SME. Covered BPMN As-Is/To-Be diagrams across six sub-processes (order design, production, inventory, field execution, finance, and cancellations), DFD Level 0 & 1, and a comprehensive ERD with around 20 tables, plus a data dictionary and CS-facing booking dashboard mockups.


Network Infrastructure

Hybrid Network Design - PT. Nusantara Tech

A multi stage Cisco Packet Tracer project designing infrastructure for a fictional company across a head office (four floors of subnets), a branch office, and a cloud/internet segment with a web server including static routing, DHCP, wireless access, OSPF, and firewall ACL rules. Documented in a formal infrastructure report.


Programming
